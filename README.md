# 🌐 Personal Portfolio Website

A modern and responsive personal portfolio website built using **HTML**, **CSS**, and **JavaScript**. This website showcases my profile, skills, projects, education, and contact information in a clean and professional design.

## 🚀 Features

- Responsive design for all devices
- Professional landing page
- About Me section
- Skills section
- Projects showcase
- Education details
- Contact information
- Smooth navigation
- Modern UI with animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Font Awesome
